# COMFYUI_WORKFLOW (COMFY-001): local concept-art generation

**Rule (owner ruling via PM, 2026-11-20; D-13/D-14 amended for these uses only):** AI-generated raster art from ComfyUI MAY ship for the cabinet bezel, cabinet illustrations, arcade background ambience (the visual backdrop), the tape texture and other "real world" interface elements. The Act 0 pixel screen, the Aether and all in-game visuals stay generated by code (CLAUDE.md §3). Conditions:
- The model's licence must permit commercial use; record the licence per model (table below) and in the sidecar of any image that ships.
- The amendment is recorded (ART-001 §14.9, TECH-001 §11.2 2026-11-20, CLAUDE.md §3; `tests/test_generated_assets_only.gd`). Shipping images live in `assets/art/comfyui/` with a `manifest.json` entry each; the output folder `research/comfyui_out/` stays local and git-ignored. Stage 1 scripts: `tools/comfyui/make_bezel.py` (fit a flat face to the 640x360 rig, exact transparent screen hole) and `tools/comfyui/stage1_finish.py` (raw renders to shipped files + manifest + contact sheet).

## Setup (done once on the owner's machine)
- ComfyUI (git clone of `comfyanonymous/ComfyUI`) at `E:\Tools\ComfyUI`, own venv (`venv\`, Python 3.12, torch cu128). Outside the repo.
- Checkpoint: `models\checkpoints\sd_xl_base_1.0.safetensors` (stabilityai/stable-diffusion-xl-base-1.0, 6.94 GB, CreativeML OpenRAIL++-M: use-based restrictions, commercial use allowed). Hardware: RTX 4070, 12 GB.
- Why this route: ComfyUI's own HTTP API (`/prompt`, `/history`, `/view`) plus a 90-line stdlib script is the smallest thing a chat can call; no third-party MCP server or extra dependency to trust. Existing MCP servers (Comfy-Org/comfy-mcp, artokun/comfyui-mcp) were found but not installed; revisit if chats need workflow editing.

## Start the server
```powershell
powershell -File tools\comfyui\start_server.ps1      # http://127.0.0.1:8188, loopback only
```
Check it is up: `curl http://127.0.0.1:8188/system_stats`. First generation after start loads the model (~20 s).

## Hand-off from a chat
```powershell
E:\Tools\ComfyUI\venv\Scripts\python.exe tools\comfyui\gen.py --prompt "<prompt>" --tag <short_name> [--seed N] [--steps 30] [--cfg 7] [--width 1024] [--height 1024] [--negative "..."]
```
Prints the PNG path and a JSON line. Default output folder: `E:\GameDev\ProjectDarkstar\research\comfyui_out\` (main checkout, git-ignored; override with `--out`). View the PNG with the Read tool.

## Logging convention
Each image gets a sidecar `<name>.json` (prompt, negative, seed, steps, cfg, size, checkpoint, seconds) next to `<timestamp>_<tag>_<seed>.png`. Always state seed and prompt when reporting an image so it can be reproduced. Until the amendment lands in the owner docs, call every image reference, not a game asset.

## Model comparison (2026-11-20, RTX 4070 12 GB, seed 1983, 1024x1024, one image per cell)
Prompts: P1 cabinet flyer (above), P2 warm 1983 arcade interior backdrop, P3 strip of worn masking tape across a coin slot with a hand-lettered warning. Times are wall-clock; the P1 cell includes model load. VRAM is whole-GPU `nvidia-smi` peak and includes ~7-9 GB of models the server keeps cached between runs, so read it as "fits in 12 GB" (peaks 10-11.7 GB), not as per-model need.

| Model | Steps | P1 s | P2 s | P3 s |
|---|---|---|---|---|
| FLUX.2 klein 4B (fp8 cast) | 4 | 13.2 | 5.0 | 5.0 |
| Z-Image-Turbo (int8) | 8 | 27.7 | 21.2 | 16.6 |
| SDXL base | 30 | 24.1 | 10.1 | 10.1 |

Observations (single seed, so indicative only; contact sheet at `research/comfyui_out/compare_sheet.png`, rows klein / Z-Image / SDXL):
- Klein: fastest by far; flyer has good neon-on-black but garbled headline text; backdrop and tape are the most photographic and convincing.
- Z-Image-Turbo: cleanest graphic flyer ("1983" legible, flat vector-like neon) and a believable warm backdrop; tape had the best coin-slot layout but mangled lettering.
- SDXL: stylised and busy; backdrop drifts to flat illustration; text is garbled everywhere. Not recommended over the two newer models.
- All three garble hand-lettered text; any readable lettering must be added in post (or by `VectorLabel`/pxl), not generated.

Recommendation (n=1, not a benchmark): cabinet illustration / flyer: Z-Image-Turbo (cleaner graphic read), klein for fast iteration and editing; arcade backdrop: klein (5 s, photographic, moody); coin-slot tape texture: klein for realism, then clean up in post. Both are Apache 2.0, so both satisfy the commercial-use condition. Note the owner's brief ranked Z-Image for photorealism and klein for stylisation; these runs showed the reverse on these prompts.

## Bezel look comparison (2026-11-20)
Script: `tools/comfyui/bezel_compare.py` (re-runs every cell). Output, local-only: `research/comfyui_out/bezel_compare/` holds the cells, `bezel_compare_sheet.png` (rows = prompts, columns = klein / Z-Image-Turbo, each cell labelled seed/steps/cfg/size/time) and `bezel_compare_log.csv` (every prompt, seed and setting). Seed 1983 for every cell; 1344x768 (about 16:9, the 640x360 reference space); klein 4 steps, Z-Image 8 steps, both cfg 1.0.
- **P0** is ART-001 quoted, not an existing prompt (none was found; the bezel was built in code): §12.7 ("a real-world object rendered at native resolution as full-colour printed cabinet art ..."), §12.7a concept, print rules and motifs, the owner's 2026-11-18 realism quote, and the surround/Fable-pass backdrop sentence, joined with " | ". The full string is in the script and the CSV.
- **P1** adds a 1983 spot-colour screenprint look (flat inks, coarse Ben-Day dots, off register, key-black keylines, no airbrush). **P2** adds heavy wear (scratches, peeling print, grime, fingerprints, chips, faded reds). **P3** adds warm tungsten/amber light and oxblood shadows.
- Observations: klein returns a flat printed card (a bezel-like poster, no cabinet, garbled title "PRTENCUL") against the backdrop and barely reacts to P1-P3. Z-Image-Turbo returns a whole cabinet-front photo, reads the prompt much more (P1 is the best screenprint, P2 adds control panel, marquee and chipped paint), and renders "Pretence" legibly. Neither gives a screen cut-out, alpha, or an exact 640x360 layout: that, plus a bezel-only frame (no room around it) and any readable text, is for the follow-up regeneration session. These are looks only.

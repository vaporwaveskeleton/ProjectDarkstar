# features/charges

Null-Iron Charges and Mourning Glass handling. Owner docs: GDD §8.2–8.3, SYS-001 §1.3–1.4, TECH-001 §2.6, §4.1, §4.3.

Status (M1 slice 3 PR 4): geodes, over-fire detonation, Mourning Glass shards, the Vigil's magnet, and firing Null-Iron Charges (PR 4). All mounted in `scenes/sector/sector_stub.tscn`, which injects the sector `Torus`.
- `sector_geode.gd` / `.tscn` (`SectorGeode`, `GeodeStats`): a HurtboxComponent on the `world` layer (biting) + HealthComponent; calm mining and over-fire. No `StaticBody2D`, so the Vigil flies through geodes (TECH-001 §2.6, Q-T76). Named `SectorGeode` because the Cabinet already has an inner class `GeodeField.Geode`.
- `geode_sandbox.gd` (`GeodeSandbox`, `GeodeSandboxStats`): the M1 sandbox layout, seeded (`map` / `loot` / `vfx` streams); registers geodes with the `LedgerCompass`; each tick moves geodes to the image nearest the Vigil (physics priority 1, after `SectorWrap`).
- `shard_field.gd` / `.tscn` (`ShardField`, `ShardFieldStats`): struct-of-arrays shard pool (no node per shard), 64 px torus grid, magnet (no drag inside the radius; off when the magazine is full), H4 flag `magnet_inverted`, Grub hooks (`grub_query_due`, `nearest_free`, `claim`, `release_claim`; PR 4 adds `take`, `is_claimed`, `stolen_total`), one MultiMesh, physics priority 30. A full pool refuses spawns (`spawns_refused`), never recycles.
- `charge_magazine.gd` (`ChargeMagazine`, `ChargeMagazineStats`): Charge pips to the cap; cues `charge_armed` per gain, `magazine_full` on reaching the cap; `try_spend`.
- `null_iron_charge.gd` / `.tscn` (`NullIronCharge`, `ChargeStats`, M1 slice 3 PR 4): Area2D on `vigil_shots`, mask `world` + `choir_hurtbox`; homes on its target hurtbox (turn PI / turn authority rad/s), ends HIT (delivers a hit of kind `null_iron_charge`; cue `charge_hit`), LOST (Grub or geode contact; cue `charge_lost`, used for interception only) or GUTTERED (life; cue `charge_gutter`). Lives under %Actors (SectorWrap re-images it).
- `charge_launcher.gd` (`ChargeLauncher`): `deploy_charge` (latched by `VigilInput.deploy_requested`) fires one Charge from the magazine toward the aim; empty = `dry_fire`. Counts outcomes and frees spent Charges. With the sector's `Composure` injected, a Charge lost to an interceptor costs −0.5 Composure and one on target costs 0 (SYS-001 §1.5), applied when the outcome is counted (`prune`).
- Data: `data/charges/{geode,geode_sandbox,shard_field,charge_magazine,charge}.tres` (`ds_charges.{geode,sandbox,shards,magazine,charge}.*`, TECH-001 §3.4). Values come from SYS-001; never edit numbers in the scripts.
- Tests in `tests/`; benchmark `tests/perf/bench_shard_field.tscn` (TECH-001 §8.3, §8.5). Automation probe `sector/field` and scenarios `m1_geode_mine`, `m1_magnet_collect`, `m1_overfire`, `m1_charge_fire`, `m1_charge_intercept` (TECH-001 §9.1).
